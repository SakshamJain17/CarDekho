Identical feature rows stay together. Imputation and encoding are fitted inside each training pipeline.

02 / SELECT

Validate on 20%.

Compare three algorithms on the same validation groups. Lowest validation RMSE selects the model.

03 / EVALUATE

Test on 20%.

Report results on independent test groups. Refit all three pipelines on complete data for the demonstration.

MAE is average absolute error in rupees. RMSE emphasizes large errors. R² compares with predicting the test-set mean. Dataset scores describe different populations and cannot be treated as a single ranking.

Historical listing prices do not establish current-market accuracy. Vehicle condition, accidents, and service history are absent. Small-dataset price units are an explicit assumption. Feature importance is descriptive, not causal.
